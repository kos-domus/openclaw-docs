## What this release is

A consolidation release one day after 2026.8.1: no breaking changes for this fleet's usage (no custom OpenClaw plugins, no external plugin SDK imports — the 2026-09-01 subpath deprecation gates remain a non-event locally). The theme is robustness: safer upgrades and recovery, reply completion after tool work, cron reliability, and a security bump on the managed Sharp dependency.

## Operator-relevant highlights

- **Linux desktop companion**: `.deb`/AppImage builds connect to a local or remote Gateway; Quick Chat from the system tray. Relevant only if the fleet ever moves to a Linux desktop control UI — currently Hermes desktop is the chosen path.
- **Sharp 0.35.4 + libheif 1.23.2** (managed dependency): fixes image-decoding vulnerabilities. Relevant to any OpenClaw install doing image work; the local CLI stays at 2026.6.8 as KB reference only.
- **Session visibility default change**: unsandboxed sessions of the same agent now see each other by default, including retained cron sessions. Shared-agent operators must set `tools.sessions.visibility` (`tree`/`self`) for narrower access. Watch item if any multi-agent OpenClaw usage returns.
- **Safer upgrades/recovery**: preserve newer config during migration, stop incomplete session migrations before claiming success, Gateway restart after failed update when package/rollback verified. Plus `openclaw update cleanup --dry-run` for retained migration originals.
- **Reply completion**: final answers after settled tool work, failure surfacing after accepted turns — fixes conversations that stopped at tool output.
- **Cron robustness**: recover valid migrated cron jobs, complete JSON when output is piped, heartbeat jobs report actual completed/skipped/failed outcome.
- **MCP response size limits**: oversized HTTP responses and SSE events rejected before parsing.
- **Hermes migration tooling fix**: upstream actively maintains the OpenClaw→Hermes bridge — directly relevant to this fleet's migration history (`procedures/migration-openclaw-legacy.md`).
