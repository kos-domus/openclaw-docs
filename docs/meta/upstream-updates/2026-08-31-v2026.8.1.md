## Operator-relevant highlights

- **Breaking — OpenProse migration**: the bundled OpenProse plugin and `/prose` command are removed. Run `openclaw doctor --fix` to clean stale configuration and follow the upstream Agent Skill migration (https://docs.openclaw.ai/prose), keeping existing `.prose` source files. (#128494)
- **Breaking — OpenAI route migration**: `openclaw doctor --fix` migrates shipped `codex/*` and `openai-codex/*` model refs, provider config, stored sessions, and automation routes to `openai/*`, retaining Codex runtime intent and flagging conflicts for operator repair. Relevant to any fleet that pins OpenAI subscription-backed provider names.
- **Upcoming deprecations (gate 2026-09-01)**: external plugins must move off `plugin-sdk-*` subpath imports (config, channel, infra runtime helpers) onto `api.pluginConfig` and focused `openclaw/plugin-sdk/*` imports. These are gates, not removals in this release; see the SDK migration guide (https://docs.openclaw.ai/plugins/sdk-migration).
- **Find past conversations**: search visible conversation text by exact words or phrases and reopen surrounding messages from a matching result. (#105057, #105635, #105585)
- **Sessions beyond your Gateway**: run work on paired devices or cloud workers, move the session workspace with it, reuse warm machines and project seeds. (#123280, #127752, #131744, #132374)
- **Durable session progress cards**: follow subagent activity and accumulating edits through reloads across web and native chat. (#125125 et al.)
- **Structured agent questions**: answer via web/native cards, messaging buttons, or plain text, with free-text alternatives and an explicit Skip path. (#109922, #110372, #130262)
- **Private credential requests**: agents can request a credential through a masked prompt without exposing the value in chat or model context, with an opt-in proxy limiting protected-secret substitution to approved destinations. (#129670, #123216, #132122)
- **Approve recurring work once**: grant automation permissions for exact operations, inspect/revoke later, require fresh approval when the job or operation changes. (#129526, #131602)
- **Interactive widgets and dashboards**: widgets in chat, pinned to session dashboards, with exact action/network-origin grants and PNG export. (#101840 et al.)
- **Defaults changed**: grounded dreaming (model-backed background memory consolidation) on by default with a Dream Diary; automatic self-learning applies scanner-approved skills by default; session reset no longer drops conversations across idle periods/day boundaries when no reset policy is configured; CPU-scaled foreground concurrency (8–16 bounded).
- **Security-adjacent**: shared credential store (team-scoped, write-only secrets, host-bound protected egress), optional 1Password broker for SecretRefs with per-secret approval, plugin provenance warnings requiring `--force` for arbitrary executable sources, ClawHub security-audit info surfaced before install.
- **External supervision**: `OPENCLAW_SUPERVISOR_MODE=external` lets an external supervisor own Gateway restarts, lifecycle, and updates — relevant to systemd-managed installs.
- **Recoverable backups**: scheduled DB backups, versioned snapshots in an operator-owned Git repo, verified restore into staging; plus `openclaw backup sqlite` snapshot commands. (#122485, #122750, #105718)
- **Experimental Fleet and Swarm**: local Docker/Podman OpenClaw cells with per-cell resources and backup/restore; Swarm fans out bounded parallel subagents from Labs.

## Upgrade decision inputs

Upgrading this host to 2026.8.1 requires planning, not a blind bump:

1. Both breaking migrations (`doctor --fix` for OpenProse and OpenAI routes) touch provider/session config on a fleet that runs subscription-backed OpenAI provider names.
2. New defaults (grounded dreaming, self-learning, session reset, CPU-scaled concurrency) change runtime behavior without explicit opt-in.
3. The 100 unapplied advisories make the gap increasingly security-relevant; the 2026.9 beta line suggests the next minor is already in flight.
