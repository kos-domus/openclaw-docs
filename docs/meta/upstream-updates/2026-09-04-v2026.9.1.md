## What this release is

The beta line promoted to stable after a week of hardening: 1,195 PRs. Theme: resilience of the update/install path itself (auto-rollback, triage agent, config preservation across failed upgrades), personal skill libraries on shared Gateways, and a broad set of ingress/secrets security fixes. No breaking changes identified for this fleet's usage (local CLI is KB reference only; production is Hermes).

## Operator-relevant highlights

- **`openclaw update` auto-rollback**: rolls back the npm candidate when post-update Doctor fails; preserves config and secret references across a failed upgrade; hands failures to a built-in triage agent; proceeds without a Gateway service. One actionable note in the release body: users on 2026.8.2 without a service manager should run `openclaw update --no-restart` once.
- **Personal skill libraries on shared Gateways** (`openclaw skills library`): keep personal skills beside the workspace set, import from ZIP, share/publish per identity. Conceptually parallel to Hermes `extraDirs` skills approach.
- **Approval cards delivered to the originating channel** (Telegram topics included) instead of stalling silently when a delegated system agent proposes config changes or restarts.
- **WhatsApp unquoted replies on quote-cache miss**: bubbles never render blank. Relevant to the family channel (Kai) pattern if OpenClaw were ever re-adopted; on Hermes this is upstream-independent.
- **Config controls**: `cron.skipMissedJobs` (skip missed recurring jobs at startup), `blockedHostnames` SSRF policy for browser/web-fetch/webhooks, `channels.<id>.enabled: false` skips plugin load.
- **Memory maintenance**: `openclaw memory reset` rebuilds derived indexes without deleting sessions; recall outcomes surfaced to the model.
- **Ingress/token safety**: bounded concurrent pre-auth reads on SMS webhooks, per-process nonce on Copilot Azure BYOK proxy, webhook rate limits isolated by client, oversized A2A JSON-RPC batches rejected.
- **Secrets redaction**: `config.get` no longer returns unredacted pre-migration snapshots; systemd unit backups no longer leak Gateway tokens.
- **Mermaid diagrams render in every chat** (Control UI + native macOS/iOS/Android apps) — nice quality-of-life signal for the Control UI trajectory.
- **Quick-start lane on fresh installs**: detects existing Claude Code/Codex logins and API keys, verifies them live, opens the web dashboard.
