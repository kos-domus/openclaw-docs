## What this release is

The September 2026 stable. Headline features: **Atomic Updates** (validate the next version against a private copy of your setup while the Gateway keeps running, then switch over and verify — recovery can restore the previous version when data/config stay compatible; NOT a rollback backup, verified pre-upgrade backup still required), **hot plugin installs** (install plugins without restarting the Gateway), **shareable conversations**, **GPT Live in meetings and phone calls**, **parallel browser pages** worked alongside the agent, **conversation archiving/cold storage** (compress older inactive history after 30 days, reopenable; off by default), guided setup for a **specialist agent team** (chief of staff + researcher + writer + reviewer via `openclaw onboard` / Control UI).

## Operator-relevant highlights

- **BREAKING — database schema 21**: agent databases upgrade to schema 21, which older builds cannot open. Rollback requires a verified pre-upgrade backup (including WAL/journal data) plus the matching older build; reinstalling an older package alone is insufficient. Users updating **from 2026.9.2** must follow the manual schema-upgrade instructions (https://docs.openclaw.ai/install/updating#updating-from-2026.9.2-across-a-schema-bump). Do not force-downgrade by editing schema markers or dropping tables.
- **Backup discipline**: rolling back the application cannot undo database migrations — verified backup before upgrading is mandatory hygiene on this line.
- **Linux desktop auto-publication**: regular stable releases now publish the Linux desktop bundle (AppImage + .deb + checksums) automatically; the `linux-stable` tag we observed is the moving companion pointer (currently v2026.9.5, `prerelease: true` in the list — it is a republish lane, not a semantic prerelease).
- **Runtime pinning**: managed Gateway/node services can pin an exact Node/Bun executable via `--runtime-path` (absolute path; invalid pin errors out instead of silently switching runtimes).
- **Local package overrides**: package updates preserve supported local edits for recovery; `--reapply-local-overrides` replays trusted changes.
- **Security posture**: maintainer/internal bucket includes 1,623 changes (regression coverage, release tooling); full changelog is 810 KB plain Markdown.
- **Astra default**: fresh OpenAI setups default to Astra as primary model when unset; existing choices untouched.
