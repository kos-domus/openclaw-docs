## What this release is

An update-reliability and Skill Workshop release. Theme: rehearsing core and plugin changes in isolated candidate state before activation, safer update rollback/recovery, agent-owned persistent Workshop skills, live browser tabs, public/revocable session transcripts, searchable meeting library, and optional Team Reports plugin. For this fleet the headline is the **Node runtime floor change** and **six plugin-SDK breaking changes**.

## Breaking changes

- **Node runtime (hard requirement)**: Node `>=24.16.0` on 24.x, or `>=26.1.0` on 26.x; Node 26 recommended. Node 22, Node 25, and earlier 24.x/26.x builds are no longer supported — upgrade Node *before* OpenClaw to prevent SQLite text truncation. macOS 11–13.4 / Linux ARMv7 Node-based installs need a supported host. Docs: `/install/node`. (#140672)
- **exec-policy SDK**: retired exec-mode/comparator helpers moved from `infra-runtime` to `execPolicy` on `openclaw/plugin-sdk/agent-harness-runtime`; use `resolveExecModePolicy`.
- **approval SDK**: approval account-resolution helpers moved to `approval-native-runtime`; full `matchesApprovalRequestFilters` contract; native channel route gates replace the generic forwarding evaluator.
- **SDK aliases**: `channel-inbound.buildChannelTurnMediaPayload` → `buildChannelInboundMediaPayload`; removed `AbortAndDrainAgentHarnessRunResult` named type (callable retained, result inferred).
- **search result callbacks**: bounded Find/Grep text now in `details.content` (was `details.truncation.content`).
- **directory result callbacks**: `LsToolDetails.content` + optional `nextAfter` replace `truncation`/`entryLimitReached`; pass `nextAfter` as `after` to continue listing.
- **agent-owned Workshop skills**: one writable Workshop collection per agent replaces workspace ownership; `skills.workshop.allowSymlinkTargetWrites` retired; `openclaw doctor --fix` migrates proven legacy skills.
- **Effective now**: Plugin SDK untrusted-named context aliases removal (eligible since Sep 8) is now in effect with this release.

## Operator-relevant highlights

- **Safer updates**: rehearse core+plugin changes in isolated candidate copies (linked and workspace-hoisted deps included); bounded repair phase for candidate-validation failures using disposable rehearsal state; recover abandoned update records without stopping a healthy matching Gateway.
- **Skill Workshop**: one persistent agent-owned collection across workspaces; full-instruction diff reviews; Doctor retires missing-draft suggestions safely.
- **Performance**: warm prompt caches preserved across updates, less work during cold session updates and memory search, worker builds reused between sessions.
- **Public session transcripts**: owners/admins can publish revocable read-only conversation text via public URL (omits tools, reasoning, files, images, widgets).
- **Meeting library**: browse saved notes, search full transcripts, export Markdown/JSONL archives from Control UI.
- **Team Reports plugin (optional)**: authenticated GitHub activity + selected Discord sources, stored history, optional model summaries.
- **Browser tabs live**: agent pages repaint in real time; macOS opens external links as native WebKit tabs that survive chat switches.
- **Recursive delegation on by default** (bounded depth/concurrency limits retained).
- **Telegram photo albums**: up to 10 photos grouped natively, order/captions/replies preserved.
- **CLI agents in model picker by default**; `gateway.cliAgents.enabled: false` to disable.
- **`openclaw docs --limit`**: bound terminal/JSON documentation results.
