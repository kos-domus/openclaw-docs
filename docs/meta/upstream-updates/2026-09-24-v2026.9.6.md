## What this release is

The fourth September-2026 stable. Headline: clearer managed-update outcomes, **recovery of unfinished work after restarts**, complete 30-day Usage reporting, a GitHub reader (public discussions and diffs beside chat), remote workspaces gaining Files/Memory/Skills, meeting notes updating as capture continues, and **optional Decision Models (TypeSafe Jev plugin, `@openclaw/typesafe`, opt-in)**. New chat models: **Claude Opus 5.5** ($4/M input, $20/M output, 1M context window), **GPT-6 Sol and Luna** (Luna at $0.10 input / $0.50 output per million vs Sol's $2/$10 — cheap batch candidate; different pricing tiers above 272k input tokens; embedded ChatGPT use requires explicitly choosing the OpenClaw runtime), **Grok 4.7**. npm install footprint reduced by **18 MiB** (less unused Bash parser material).
