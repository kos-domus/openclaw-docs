## Release body — verified highlights (body read in full, 106KB)

- **Update safety**: updates back up every state and agent database before migrations, restore on rollback, take consistent snapshots while the Gateway keeps writing, stop before schema changes when snapshot cleanup fails (#158163, #158317, #156265).
- **Upgrades from 2026.9.5 fixed**: managed updates no longer always roll back with a stack overflow; Windows updates finish after state migration; verified macOS app handoffs activate; interrupted npm package updates recover (#157273 et al.).
- **OpenAI Agents API plugin**: run agents on OpenAI-hosted or self-hosted environments — streamed replies, steering, live web search, OpenClaw tools/attachments/hosted files, persona + workspace context (#151176 et al.).
- **Sign in with ChatGPT (Beta)**: new OpenAI auth choice beside Codex login and API keys (#148567 et al.).
- **Gateway responsiveness**: transcript writes, projections, cold history, artifact reads, avatars, roster discovery moved off the Gateway main thread — busy chats no longer stall everyone else (#147914 et al.).
- **Worktree sessions**: isolated managed worktree chats from web/iOS/Android — parallel sessions on one repo no longer collide (#100788).
- **Chat-driven setup**: owners can hand agents API keys / config changes / skill edits directly in chat; change approvals complete in the requesting chat with Allow once / Deny buttons or `/approve <id>` (#158120 et al.).
- **Config**: `${VAR:-default}` fallback syntax in environment substitution (#155164) — fixes expressions passing through unresolved.
- **Channels**: `requireMentionInBotThreads: false` accepts unmentioned follow-ups only in bot-created threads, across Discord/Slack/Telegram/Matrix/Mattermost/Teams/iMessage/Feishu (#157713).

## Known issues (from release body)

- **Windows updates from 2026.9.6** can exit silently with code 13 — run `openclaw update` again.
- **Docker/OverlayFS update time**: faster than before but still several minutes (Gateway stopped for package swap).
